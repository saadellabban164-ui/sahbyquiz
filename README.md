# صاحبي عارفني؟ — How Well Do You Know Me?

تطبيق اختبارات عربي أولًا للأصحاب والمدرسين والمرتبطين، مع Firebase Authentication وFirestore وCloud Functions وPWA.

## تخصيص حسب نوع الاختبار

- **أصحاب:** مكتبة الأسئلة العامة + أسئلة مخصصة.
- **مرتبطين:** أسئلة مختارة تلقائيًا عن الذكريات والتفاهم والصفات والعلاقة، مع إمكانية إضافة أسئلة مخصصة.
- **مدرس وطلاب:** لا تظهر أسئلة المكتبة للمدرس؛ المدرس يكتب كل الأسئلة بنفسه، ويختار نوع الإجابة، ويكتب الاختيارات عند الحاجة، ويحذف ويرتب الأسئلة قبل النشر. الطالب يدخل اسمه ويحل مرة واحدة لكل جهاز، وتظهر نتائجه للمدرس في لوحة الإدارة.

## الحساب والإدارة

تسجيل الدخول اختياري عبر Email/Password أو Google. يوجد رابط إعادة تعيين كلمة المرور، تسجيل خروج، وحذف الحساب. الحساب المتصل يعرض اختبارات المالك ومشاركات الطلاب، مع إمكانية حذف الاختبارات والنتائج. من غير حساب يظل المسار المحلي متاحًا.

## تشغيل Firebase Hosting

ملف `firebase-config.js` مرتبط بمشروع `sahby-arifny` ويحتوي فقط على إعدادات Web العامة، وليس مفاتيح Admin. ملف `.firebaserc` يحدد المشروع. للنشر من جهاز عليه Firebase CLI مسجّل:

```bash
npx firebase-tools login
npx firebase-tools deploy --project sahby-arifny --only hosting,firestore:rules,functions
```

في بيئة التطوير الحالية، فشلت محاولة النشر لأن Firebase CLI غير مسجّل بحساب يملك صلاحية المشروع. الموقع والكود جاهزان، ولا تحتاج لإضافة أي مفتاح Admin إلى المستودع.

## تقارير المدرسين

وظيفة `sendTeacherReports` المجدولة تبحث عن النتائج المستحقة بعد 24 ساعة وترسل PNG إلى إيميل المدرس عبر Resend بعد ضبط `RESEND_API_KEY`. لا تضع المفتاح في الواجهة أو GitHub.

## الفحص المحلي

```bash
python3 -m http.server 3000
```

افتح `http://localhost:3000`. تم فحص JavaScript، Firebase config، شاشة الحساب، شاشة إنشاء اختبار المدرس، وأوضاع الأسئلة.
